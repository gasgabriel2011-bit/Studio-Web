# Studio Web

Site vitrine front-end pour presenter une activite de developpeur web freelance.

## Fichiers principaux

- `index.html` : structure de la page
- `styles.css` : design responsive et animations
- `script.js` : contenus modifiables, projets, offres, simulateur et formulaire visuel

Le site est statique et peut etre ouvert directement dans un navigateur ou deploye sur GitHub Pages, Vercel, Netlify ou tout autre hebergement front-end.
